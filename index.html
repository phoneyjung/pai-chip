วิธีสร้าง Firebase ฟรี (5 นาที) ▾
  1. เข้า console.firebase.google.com → สร้างโปรเจกต์ใหม่ (ปิด Google Analytics ได้)
  2. เมนู Build → Realtime Database → Create Database → เลือก Singapore → เลือก Start in test mode
  3. แท็บ Rules วางกฎนี้แล้วกด Publish (test mode หมดอายุ 30 วัน) 
    {
  "rules": {
    "paiToken": { ".read": true, ".write": true }
  }
}
  4. แท็บ Data กดคัดลอกลิงก์ด้านบน (ขึ้นต้น https:// ลงท้าย firebasedatabase.app) แล้ววางในช่องด้านบน
